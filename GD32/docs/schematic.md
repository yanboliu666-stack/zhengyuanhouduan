# 微型四向红绿灯 · 原理图与接线（GD32E230C8T6）

> 面向对象：负责硬件/原理图的同事。
> 逻辑灯位编号、相位号与 GPIO 映射必须与
> [`docs/gd32-firmware-spec.md`](gd32-firmware-spec.md) §3 完全一致。

---

## 1. 器件选型

| 器件 | 型号/规格 | 数量 | 说明 |
|---|---|---|---|
| MCU | **GD32E230C8T6**（LQFP48） | 1 | Cortex-M23，64KB Flash / 8KB SRAM |
| 红/黄/绿 LED | 3mm 或 5mm，`Vf≈2.0~2.2V`（红/黄）`Vf≈3.0~3.2V`（绿） | 各 4 = 12 | 共阳或共阴皆可，见 §3 |
| 限流电阻 | **330Ω ~ 1kΩ**（按亮度调，建议 470Ω） | 12 | 3.3V 下约 1~5mA |
| USB 转 TTL | **3.3V 电平**（CH340/CP2102/FT232） | 1 | 连 USART0 |
| 晶振 | 8MHz（或直接用内部 HSI） | 可选 | GD32E230 可用内部 RC |
| 电源 | 3.3V（LDO/开发板） | 1 | 全板 3.3V |
| SWD 排针 | 2×2（VDD/SWDIO/SWCLK/GND） | 1 | 下载/调试 |

| PA3 | 东 E · 红灯 | 同上 |
| PA4 | 东 E · 黄灯 | 同上 |

| PA6 | （未用于灯位） | — |
| PA7 | （未用于灯位） | — |

| **PB5** | 西 W · 黄灯 | 同上 |

| **PB9** | 南 S · 红灯 | 同上 |
| **PA9** | **USART0 TX** | 接 USB-TTL 的 **RX** |
| **PA10** | **USART0 RX** | 接 USB-TTL 的 **TX** |
| PA13 | SWDIO | 调试 |
| PA14 | SWCLK | 调试 |
| NRST | 复位（10kΩ 上拉到 3.3V + 100nF 到 GND） | 复位电路 |

> 若板子不同，只需改 `config.h` 的映射，逻辑不变。

## 3. LED 接线（推荐：GPIO 高电平点亮 / 共阴）

```
       3.3V
        │
        │  （不接，共阴时 LED 阳极接 GPIO）
        ▼
    ┌───┴───┐
    │  LED  │ 阳极
    └───┬───┘
        │
       [R]  限流电阻 470Ω
        │
        ▼
      GPIO（PA0..PA8 / PB4..PB9）   ← 输出高 = 点亮；输出低 = 熄灭
        │
       GND（LED 阴极直连 GND）
```

- **共阴接法（推荐）**：LED 阴极接 GND，阳极经限流电阻接 GPIO。GPIO 推挽输出高电平
  点亮。固件 `gpio_bit_set(port, pin)` = 亮、`gpio_bit_reset` = 灭（与固件灯驱动一致）。
- **电阻取值**：红/黄 LED 压降约 2V，`(3.3-2.0)/470Ω ≈ 2.8mA`；绿 LED 压降约 3V，
  `(3.3-3.0)/470Ω ≈ 0.6mA`（偏暗）。绿色建议 **330Ω** 提亮、红/黄用 **470Ω**；
  也可统一 330Ω，亮度更高但电流约 4~8mA，仍在 GPIO 能力内。
- **并发负载**：任意时刻最多 4 盏灯同亮（1 绿 + 3 红，或黄闪时 4 黄），
  总电流约 4×3mA ≈ 12mA，3.3V 稳压与 GPIO 均无压力。

## 4. 串口 / 供电 / 调试接线

```
 USB转TTL(3.3V)                     GD32E230C8T6
 ┌─────────────┐                    ┌──────────────┐
 │  TX  ────────────────────────────▶ PA10 (RX)    │
 │  RX  ◀──────────────────────────── PA9  (TX)    │
 │  GND ────────────────────────────▶ GND          │
 │ (VCC 3.3V 可给板供电，需确认电流)  ──▶ 3.3V        │
 └─────────────┘                    └──────────────┘

 SWD 调试                          GD32E230C8T6
 ┌─────────────┐                    ┌──────────────┐
 │ SWDIO ──────────────────────────▶ PA13         │
 │ SWCLK ──────────────────────────▶ PA14         │
 │ VDD   ──────────────────────────▶ 3.3V         │
 │ GND   ──────────────────────────▶ GND          │
 └─────────────┘                    └──────────────┘
```

注意事项：

1. **电平必须 3.3V**：GD32E230 的 IO 不兼容 5V；USB 转 TTL 必须选 3.3V 档/型号。
2. **共地**：USB-TTL 的 GND 必须与 GD32 的 GND 相连。
3. **交叉接线**：USB-TTL 的 TX → GD32 的 RX(PA10)，USB-TTL 的 RX → GD32 的 TX(PA9)。
4. **去耦**：每个 VDD/VDDA 引脚就近接 100nF 电容到 GND；NRST 10kΩ 上拉 + 100nF 到 GND。
5. **BOOT0 接地**：确保从主 Flash 启动。

```
                          ┌────────────────────────────────────┐
  [宿主机 PC / RK3588]     │   GD32E230C8T6 微型信号机            │
  host/main.py            │                                    │
     │  USB转TTL(3.3V)    │   PA0─[R]─● N红    PA3─[R]─● E红     │
     │  TX→PA10           │   PA1─[R]─● N黄    PA4─[R]─● E黄     │
     │  RX←PA9            │   PA2─[R]─● N绿    PA5─[R]─● E绿     │
     │  GND──GND          │   PB9─[R]─● S红    PB6─[R]─● W红     │
     └────────────────────┘   PB8─[R]─● S黄    PB5─[R]─● W黄     │
                             PB7─[R]─● S绿    PB4─[R]─● W绿     │
                             PA9=TX  PA10=RX  PA13/14=SWD       │
                          └────────────────────────────────────┘
                             ┌──────────────────────────────┐
                             │  微型红绿灯模型（四向 × 红黄绿）  │

                             │    ●红 ●黄 ●绿                 │
                             │  W ●       ●  E                │
                             │         S                     │
                             └──────────────────────────────┘
```

## 6. 上电自检建议（硬件侧）

- [ ] 万用表确认 3.3V 与 GND 无短路。
- [ ] 逐个 LED 确认极性正确、电阻焊接无误（可用固件测试点灯命令或临时拉高 GPIO）。
- [ ] USB-TTL 回环测试：短接其 TX/RX，串口助手能回显，确认模块与电平正常。
- [ ] SWD 能被 J-Link/ST-Link/CMSIS-DAP 识别并擦除/下载。
